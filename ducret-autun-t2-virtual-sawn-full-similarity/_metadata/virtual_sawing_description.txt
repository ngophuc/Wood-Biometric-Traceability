Each query crop is sampled from ducret-autun-t2-cut-align-full-similarity, which is registered to the fresh ducret-autun-t1-orig source log in orientation, scale, translation and raw image size. The crop rectangle is therefore recorded directly in T1 source coordinates and used as localization ground truth. The query is rotated by query_rotation_deg without any spatial upscaling. expected_alignment_angle_deg is the inverse right-angle rotation required to restore the source orientation.
